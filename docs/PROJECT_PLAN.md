# Project Plan: Legal Case Tracking SaaS (Pan-India)

## Executive Summary
**Project Name**: NyayaTrack (Pan-India)
**Goal**: Automate case tracking for Indian Advocates (High Courts, District, Revenue) with Real-Time WhatsApp Alerts.
**Strategy**: **Broad POC First** (Validate all portals) -> **Universal Scraper Engine** (Deep Dive).
**Timeline**: **18-20 Weeks** (4.5 - 5 Months).
**Budget**: **₹2.6L - ₹3.0L** (Development) + **~₹15k/mo** (Operational).

## Roadmap Overview

| Phase | Duration | Focus Area | Deliverables |
| :--- | :--- | :--- | :--- |
| **Phase 0** | **Weeks 1-4** | **Broad POC** | Connectivity Proofs for eCourts, HC, Revenue, Land, WhatsApp, Voice & Legacy APIs. |
| **Phase 1** | **Weeks 5-8** | **Universal Engine** | Production-grade Scraper Core + Adapters for RJ, DL, UP. |
| **Phase 2** | **Weeks 9-11** | **Backend Core** | User Roles, Subscription, Admin Panel. |
| **Phase 3** | **Weeks 12-15**| **Intelligence** | Voice-to-Text Pipeline + Indian Kanoon RAG. |
| **Phase 4** | **Weeks 16-19**| **Frontend (PWA)** | Advocate Dashboard, Daily Cause List, Client Alerts. |
| **Phase 5** | **Week 20**    | **Deployment** | Production Setup, Docs, Handoff. |
